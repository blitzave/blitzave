# Code of Conduct

BlitZave adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every project space: GitHub issues, pull requests
and discussions, and the BlitZave Discord.

In the spirit of the product: be an ally, never a scorekeeper. Be patient with
newcomers, assume good faith, and remember that money is personal. Never ask
anyone to share their real financial details, and never share someone else's.

## Reporting

If you experience or witness unacceptable behavior, message a maintainer
privately on [Discord](https://discord.com/invite/VerUYP67). Reports are
handled confidentially. Maintainers follow the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
